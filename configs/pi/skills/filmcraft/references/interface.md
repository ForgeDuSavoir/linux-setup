# FilmCraft interface — orientation

Official sources: [FilmCraft README](https://github.com/storytold/filmcraft#features), [agents and MCP tools](https://github.com/storytold/filmcraft/blob/main/docs/agents.md), [GUI control protocol](https://github.com/storytold/filmcraft/blob/main/docs/control-protocol.md), [project files and media relinking](https://github.com/storytold/filmcraft/blob/main/docs/project-files.md), [keyboard shortcuts](https://github.com/storytold/filmcraft/blob/main/docs/keyboard.md).

FilmCraft provides Editing, Assembly, Color, Effects and Audio workspaces. The Project panel contains bins and media; the Source monitor previews an item before it is placed; the Program monitor shows the sequence; the Timeline holds video tracks (V1…) and audio tracks (A1…). Effect Controls handles clip effects and keyframes; the Properties panel shows the selected item's properties. Color has grading controls and scopes; Audio has track and clip mixers. Panel visibility and layout depend on the current workspace and may change across releases: verify with `ui_inspect`, `ui_elements` or a screenshot, rather than assuming a position.

The source media, project (`.fcproj`) and sequence are distinct: project items have ids, and timeline clips refer to these items. `project_inspect` and `sequence_inspect` supply ids and timing; `command_list` supplies actual menu paths, shortcuts and command parameters. Use the GUI to teach; use the MCP bridge to observe, not to replace a user's manual learning unless asked.

For OBS pre-edits created by `pre-edit`, FilmCraft imports Auto-Editor's Premiere/FCP7 XML, saves a `.fcproj`, then relinks the source video by a relative path. If the media is missing, inspect first and explain File > Link Media; avoid overwriting or changing the source until the user agrees. FilmCraft has transcript-based `transcript.removePauses`, but this installed build cannot transcribe internally (compiled without Whisper); it is not the same as Auto-Editor's -34 dB audio threshold.
